# ERRC: Competitive Gap Grid

Read ~/.claude/skills/_shared/landing-page-psychology.md before starting.

## 1. Inputs
- The client's page/offer and 2–5 competitor pages (URLs or pasted copy). Ask if missing.
- If you have web access, fetch the pages. Otherwise ask the user to paste the content.

## 2. Score
Make a table: rows = the 9 principles, columns = client + each competitor, cells = 0–2 scores. Add totals. Below it, note what each competitor does best.

## 3. Industry norms
List what every competitor does (table stakes) and what none of them do (open space): offer, messaging, proof types, page structure, pricing, guarantee.

## 4. ERRC grid
Fill each quadrant with 3–6 specific items tied to the scores and norms:
- ELIMINATE: things the industry takes for granted that hurt conversion (e.g. walls of text, carousel-only proof, fake urgency, tone mismatch)
- REDUCE: things overdone well past what buyers need (e.g. feature lists, polished stock assets, badge clutter)
- RAISE: things to push well above the industry (e.g. proof density and specificity, authority placement, chunking)
- CREATE: things nobody in the market offers (e.g. a "before" story, a curiosity-gap headline, native proof, a named framework, real scarcity)

## 5. Output
- Score table
- ERRC grid
- A one-sentence positioning statement that comes out of the grid
- Top 3 actions to hand to /steady

## Rules
Base every item on evidence from the pages. Never invent competitor claims or client proof.
