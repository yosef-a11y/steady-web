# Steady: Landing Page Builder

Read .claude/skills/_shared/landing-page-psychology.md before starting.

## 1. Intake (ask for anything missing, don't guess)
- Client, offer, price, target customer, main CTA
- The customer's "before" state: pains, failed attempts, desired outcome
- Proof: specific results with numbers, testimonials, screenshots, raw founder/client video
- Authority: credentials, client/media logos, speaking, years, volume
- Real urgency or scarcity, if any
- Existing page URL or copy (if this is an audit)

## 2. Audit mode (existing page)
- Score the page 0–2 on all 9 principles in a table with a one-line reason each.
- List the top 5 fixes ranked by expected conversion impact, each with rewritten copy.

## 3. Build mode (new page)
Write the full page in the reference's page order. For each section give:
- Section name and its goal
- Headline / subhead
- Body copy (chunked)
- Visual/asset direction (which proof or image goes here)
- CTA text

Give 3 headline variants for the hero.

## 4. Before delivering
Run the pre-ship checklist and show pass/fail for each item. Fix any failures before final output.

## Rules
- Never invent testimonials, numbers, credentials, logos, urgency or scarcity. Use [PLACEHOLDER: needed asset] instead.
- Plain, human voice. No corporate filler.
